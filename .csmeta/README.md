## Regenerating

```bash
# Auto-scan (repos with standard FQL pattern):
cd <repo> && fqlmeta generate --verbose

# Manual extraction (repos with common.FQLProperty):
grep -oP 'common\.FQLProperty = "\K[^"]+' <file>

# Copy output to this dir:
cp .csmeta/*.cue <falcon-cli-fork>/.csmeta/
```
